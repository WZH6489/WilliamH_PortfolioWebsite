Postfix Calculator

A C++ command-line calculator that evaluates postfix (reverse Polish) expressions using a stack — no parentheses, no operator precedence rules, just clean LIFO arithmetic.

  • C++
  • Stack
  • CLI
  • Standard Library

Why postfix

Infix arithmetic forces a parser to manage precedence, associativity, and parentheses before it can evaluate a single digit. Postfix — also called Reverse Polish Notation — sidesteps all of that: operands push, operators pop, and the answer falls out the top of the stack. Cleaner code, faster evaluation, and a much smaller surface area for bugs.

What it does

  • Evaluates well-formed postfix expressions (e.g. 3 4 + 2 * = 14).
  • Supports the four core arithmetic operators (+   −   ×   ÷).
  • Ships a small command set: clear, print, help, quit.
  • Rejects malformed input with a clear, recoverable error — the calculator never crashes.

How it’s built

A single-translation-unit C++ program built around the standard library’s std::stack. Tokens are pulled from std::cin, classified as operand or operator, and either pushed or used to pop the top two operands and push the result.

Error handling is treated as a first-class concern, not an afterthought: empty-stack pops, division by zero, and unknown tokens each produce a labelled error and return control to the prompt without losing the rest of the session.

Results

  • 100% edge-case pass rate against the assigned test suite — empty input, single-operand input, operator-only input, divide-by-zero, mixed whitespace.
  • O(n) evaluation in the length of the expression — one pass over the input.
  • Zero crashes during stress testing with malformed input streams.

What I’d do next time

  • Add an infix-to-postfix shunting-yard front end so the same engine can take human-style input.
  • Generalise the operand type from int to double behind a template parameter.
  • Wire up a tiny test harness so the edge-case suite runs on every commit.
